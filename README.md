# Lexical-Analyser
Developed a Compiler Design Lexical Analyzer in C programming language to process .c source files and tokenize keywords, identifiers, operators, symbols, constants, and literals. Implemented comment handling and preprocessor directive recognition using file handling and character-by-character scanning techniques.

# Features
- Reads and analyzes .c source files
- Identifies keywords, identifiers, operators, symbols, and constants
- Supports string literals and character literals
- Handles single-line and multi-line comments
- Detects preprocessor directives
- Implements tokenization using character-by-character scanning

# Technologies used
- Advanced C 
- File operations
- Functions
- Makefiles
- Command line arguments

# How to Run
1. Compile:
  gcc main.c lexical.c -o lexer

2. Execute:
  ./lexer <input_file.c>
